## 배송이 왜 이렇게 중요한가

**배송은 브랜드 경험의 마지막 터치포인트입니다.**

시청자가 영상 시청 → 쇼핑몰 구매 → **받는 순간까지가 크리에이터 브랜드 경험**입니다. 여기까지 만족스러워야 재구매·구독 유지·주변 추천으로 이어집니다.

### 배송 만족도 vs 재구매율 (TubePing 파트너 데이터)

| 배송 만족도 | 재구매율 |
|---|---|
| 1점 (최악) | **10% 이하** |
| 3점 (보통) | 20~25% |
| 5점 (최고) | **40%+** |

→ **만족도 1점 차이 = 재구매율 4배 차이**.

## 배송 노하우 10가지

### ✅ 1. 출고 기한을 명확히 하라

**"2~3일 내 출고"는 막연합니다.** "주문 후 1영업일 내 출고, 오후 3시 이전 주문 당일 출고"처럼 구체적이어야 합니다.

구매자 불안 해소 포인트:
- 언제 발송되는지
- 배송이 얼마나 걸리는지
- 송장 조회는 어디서

### ✅ 2. 송장 번호는 자동 발송

**주문자에게 카톡/문자 자동 발송 = CS 문의 50% 감소** (TubePing 파트너 평균).

대부분 쇼핑몰 솔루션(카페24·스마트스토어)에서 자동화 가능.

### ✅ 3. 포장에 크리에이터 감성을 담아라

**일반 택배 박스 vs 크리에이터 로고 박스 = 개봉 경험이 완전히 다릅니다.**

필수 요소:
- 크리에이터 로고·캐릭터 박스
- 손편지 또는 공통 감사 카드
- 구독자 혜택 쿠폰 (다음 구매 유도)

💡 **팁**: "인스타에 올리고 싶어지는" 요소 하나 추가 → **무료 UGC 마케팅** 발생. TubePing 파트너 중 언박싱 SNS 공유율 18% 기록 사례 있음.

### ✅ 4. 파손 방지 포장은 기본

**뽁뽁이 2겹, 모서리 보강, 충격 흡수재 필수.**

특히 유리·도자기·전자기기는 반드시 **완충 테스트** 후 발송.

### ✅ 5. 배송 상자 크기를 상품에 맞춰라

**상품 < 박스 크기 = 내부 굴러다님 → 파손 위험.**

크기 3~4종으로 다양화해 상품별 맞춤 박스 사용.

### ✅ 6. 배송 업체를 신중히 선택하라

**초기에는 CJ대한통운 추천** — 배송 사고가 가장 적습니다.

| 택배사 | 특징 | 추천 상황 |
|---|---|---|
| **CJ대한통운** | 안정적, 비쌈 | 고가 상품 |
| 한진택배 | 가격·안정성 중간 | 일반 상품 |
| 로젠택배 | 저렴, 불안정 | 저가 상품 |
| 우체국택배 | 도서산간 유리 | 소형 상품 |

### ✅ 7. 반품·교환 프로세스를 단순화하라

**복잡하면 구매자가 포기하고 불만만 쌓입니다.**

이상적 프로세스:
1. 쇼핑몰에서 반품 신청 (클릭 1번)
2. 자동으로 반품 송장 생성
3. 택배 기사가 수거
4. 도착 확인 후 자동 환불

### ✅ 8. 배송 지연 시 선제 공지

**구매자가 문의하기 전에 먼저 공지 = 불만이 감사로 바뀝니다.**

공지 내용:
- 지연 이유 (솔직히)
- 예상 배송일
- 보상 (쿠폰·사은품)

### ✅ 9. 배송 데이터를 분석하라

**매월 확인할 핵심 지표 4개:**

- 평균 출고 소요 시간
- 배송 클레임률
- 반품·교환 사유 TOP 5
- 고객 만족도 (NPS)

데이터를 보면 **어디를 개선해야 할지** 보입니다.

### ✅ 10. 첫 구매자에게는 특별한 무언가

**첫 경험이 좋으면 평생 고객이 됩니다.**

아이디어:
- 손글씨 메모 (자동 생성 OK)
- 크리에이터 시그니처 스티커
- 다음 구매 20% 쿠폰
- 작은 사은품 (단가 1~2천 원)

## 배송 직접 하면 시간이 얼마나 걸리는가

**주문 100건 기준 주당 7~8.5시간 소요됩니다.**

| 작업 | 소요 시간 |
|---|---|
| 주문 확인·정리 | 1시간 |
| 상품 피킹 | 2시간 |
| 포장 | 3~4시간 |
| 송장 출력·부착 | 1시간 |
| 택배 접수 | 30분 |
| **총 시간** | **7~8.5시간** |

**주 2회 공구 = 주당 15시간 손실**. 이 시간이면 영상 2~3개 제작 가능.
