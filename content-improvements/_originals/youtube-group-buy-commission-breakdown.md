# 유튜브 공구 수수료 현실 — 크리에이터가 실제로 받는 수익 구조 완전 분해

"공구 한 번 하면 얼마 남아요?"

크리에이터 커머스를 시작하려는 분들이 가장 많이 묻는 질문입니다. 답은 **방식에 따라 천차만별**입니다. 같은 상품을 팔아도 누구는 10%, 누구는 40%를 가져갑니다.

이 글에서는 크리에이터가 상품을 팔 때 선택할 수 있는 **4가지 수익 구조**를 실제 숫자로 분해합니다. 본인 채널에 맞는 모델을 선택하는 데 도움이 됩니다.

## 전체 비교표 (1만 원짜리 상품 기준)

| 방식 | 크리에이터 수익 | 운영 부담 | 재고 리스크 |
|------|--------------|----------|-----------|
| 제휴 마케팅 (쿠팡파트너스) | 100~1,000원 (1~10%) | 없음 | 없음 |
| 광고 협찬 | 건당 고정비 (30~500만) | 낮음 | 없음 |
| 일반 공구 (직접) | 2,000~4,000원 (20~40%) | 매우 높음 | 높음 |
| 자체 쇼핑몰 (직접) | 3,000~5,000원 (30~50%) | 매우 높음 | 높음 |
| 풀필먼트 (튜핑 등) | 1,500~3,000원 (15~30%) | 없음 | 없음 |

## 1. 제휴 마케팅 — 가장 쉽지만 가장 박함

**수익률: 1~10%**

쿠팡 파트너스, 네이버 쇼핑 파트너 등을 통해 영상 설명란에 링크를 달고 수수료를 받는 방식.

### 장점
- 오늘 시작 가능 (심사만 통과하면)
- 재고/배송/CS 일체 없음
- 영상 한 번 올리면 계속 수익

### 단점
- 수수료 1~10%로 매우 낮음
- 쿠팡/네이버가 플랫폼을 바꾸면 속수무책
- 구매자 데이터를 크리에이터가 못 가짐

**예시:** 1만 원짜리 상품을 100명이 사면 → 수익 10,000원~100,000원

## 2. 광고 협찬 — 고수익이지만 불규칙

**수익: 건당 30만~500만 원 (구독자 규모에 따라)**

브랜드가 돈을 주고 제품을 소개해달라고 하는 구조. 판매 수수료가 아니라 **콘텐츠 제작비**를 받습니다.

### 장점
- 고정 수익 (판매 여부 무관)
- 단가가 높음
- 재고/CS 없음

### 단점
- 수입이 불규칙 (이번 달 3건, 다음 달 0건)
- 과도하면 구독자 이탈
- 브랜드에 의존적

**예시:** 구독자 10만 채널이 월 2건 협찬 → 월 200~600만 원

## 3. 일반 공구 (직접 운영) — 수익률 최고, 피곤함도 최고

**수익률: 20~40% (실질 마진)**

상품을 도매로 사서 직접 포장·발송·CS하는 전통적인 공구 방식.

### 수익 분해 (1만 원 상품 기준)

| 항목 | 금액 |
|------|------|
| 판매가 | 10,000원 |
| 원가 (도매) | 5,000~6,000원 |
| 배송비 | 2,500원 (구매자 부담) |
| 결제 수수료 (카드) | 300원 |
| 포장 자재 | 300원 |
| **실질 마진** | **3,400~4,400원** |

### 장점
- 마진율이 가장 높음
- 가격 완전 통제
- 구매자 데이터 보유

### 단점
- 시간 투자 어마어마 (주 20시간+)
- 재고 리스크 (안 팔리면 손해)
- CS 부담 (하루 종일 메시지)
- 초기 자본 필요

## 4. 자체 쇼핑몰 (직접 운영) — 브랜드 구축 가능

**수익률: 30~50%**

카페24, 스마트스토어 등으로 자체 쇼핑몰을 만들어 운영하는 방식.

### 공구와 다른 점
- 상시 판매 (공구는 오픈 기간만)
- 여러 상품 동시 판매
- 재방문 구매자 축적
- 브랜드 축적

### 단점
- 공구보다 운영 부담 더 큼
- 마케팅·SEO 등 추가 작업
- 쇼핑몰 구축·디자인 비용

## 5. 풀필먼트 서비스 (튜핑 등) — 시간 대비 효율 최고

**수익률: 15~30%**

크리에이터는 상품 선택과 콘텐츠 제작만 하고, 나머지(소싱·쇼핑몰·배송·CS·정산)는 전문 팀이 전담하는 방식.

### 수익 분해 (1만 원 상품 기준)

| 항목 | 금액 |
|------|------|
| 판매가 | 10,000원 |
| 원가 (풀필먼트사 부담) | 0원 |
| 운영비 (풀필먼트사 몫) | 6,000~7,000원 |
| **크리에이터 수익** | **1,500~3,000원 (15~30%)** |

### 장점
- **시간 투자 주 3~5시간** (일반 공구의 1/5)
- 재고 부담 0, 초기 자본 0
- CS 부담 0
- 상품 소싱 자동화 (데이터 기반 추천)

### 단점
- 마진율이 직접 운영보다 낮음
- 파트너사 정책에 따라야 함

## 어떤 방식이 유리한가?

상황별 추천:

| 상황 | 추천 방식 |
|------|----------|
| 구독자 1~3만, 운영 경험 없음 | 제휴 마케팅 + 협찬 |
| 구독자 3~10만, 시간 있음 | 일반 공구 (테스트용) |
| 구독자 10만+, 콘텐츠 몰입 | 풀필먼트 (튜핑) |
| 구독자 30만+, 팀 있음 | 자체 쇼핑몰 |

## 시간 vs 수익 트레이드오프

**핵심은 "시간 대비 효율"입니다.**

- 일반 공구: 월 500만 원 벌지만 주 20시간 투입 → 시급 환산 시 낮음
- 풀필먼트: 월 300만 원 벌지만 주 3시간 투입 → 시급 환산 시 더 높음
- 남는 17시간으로 콘텐츠 추가 제작 → 채널 성장 → 장기 수익 배가
